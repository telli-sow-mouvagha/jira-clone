Jira clone est un projet de reconstruction de l'application Jira.

### État actuel
- Pour l'instant, l'initialisation a été réalisée avec Bun, shadcn, Next.js, React.js, TypeScript enfin TailwindCSS.
- Quelques tests d'interface (UI) ont été réalisés pour comprendre React.

### Objectif
- Intégrer l'interface globale et la gestion de tickets
